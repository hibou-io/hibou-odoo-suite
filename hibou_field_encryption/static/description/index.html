Field Encryption

This module allows users to store encrypted field values in the database. Multiple fields can be stored in a single encrypted field. Values are serialized and encrypted before storing, and automatically decrypted and deserialized when read.

Requirements

pip install cryptography

Configuration

Set the encryption key in the server config file:

rec_encryption_key=<YOUR_KEY>

Alternatively, set it as an environment variable (useful for secret managers and container deployments):

export REC_ENCRYPTION_KEY=<YOUR_KEY>

The module checks the Odoo config file first, then falls back to the environment variable.

Generate a key using Python:

from cryptography.fernet import Fernet
Fernet.generate_key().decode()

Usage

Protect sensitive data in your models using the encrypt=True shorthand. A rec_encrypted Encryption field is created automatically:

from odoo import fields, models

class Partner(models.Model):
    _inherit = 'res.partner'

    secret_note = fields.Char(encrypt=True)

Multiple fields on the same model share the same encrypted blob:

class Partner(models.Model):
    _inherit = 'res.partner'

    secret_note = fields.Char(encrypt=True)
    ssn = fields.Char(encrypt=True)

You can also declare the Encryption field explicitly and reference it by name:

class Partner(models.Model):
    _inherit = 'res.partner'

    encrypt = fields.Encryption()
    secret_note = fields.Char(encrypt='encrypt')

Migration Helper

When converting existing plaintext columns to encrypted storage, use the migration helper in a post-migration.py script or post_init_hook:

from odoo.addons.hibou_field_encryption.models.fields import migrate_fields_to_encryption

def migrate(cr, installed_version):
    migrate_fields_to_encryption(
        cr,
        table='res_partner',
        field_names=['secret_note', 'ssn'],
    )

    # Optionally drop the old plaintext columns:
